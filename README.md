# Trabalho-hospital-TC

Este é um projeto relacionado ao curso técnico em informática integrado ao ensino médio da Escola Técnica Estadual Monteiro Lobato, com finalidade unicamente acadêmica, sendo desenvolvido por Theo Keller Paiva, Adam Romão Dientsmann e Ygor Marcadenti Squena.

Ele está sendo feito conforme as requisições da Fundação Hospitalar Dr. Oswaldo Diesel.

A aplicaçãos é projetada para facilitar a coleta de dados de satisfação dos pacientes do hospital. Mais informações serão adicionadas em breve, ou entre em contato: theokpaiva@gmail.com
